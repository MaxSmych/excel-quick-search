# Excel Search — быстрый поиск по Excel

Лёгкое desktop-приложение для live-поиска по любому Excel-файлу (`.xlsx` / `.xls` / `.xlsb`)
с выбором отображаемых колонок, пофильтрами по каждой колонке, подсветкой совпадений,
отметками найденных строк и экспортом в CSV.

Одно окно, один скрипт, без установки. Тема — Catppuccin Mocha.

## Возможности

- **Live-поиск** — результат обновляется по мере ввода, ищет сразу по всем выбранным колонкам.
- **Выбор колонок** — чекбоксы слева включают/выключают видимость; настройка запоминается.
- **Пофильтры по колонке** — узкое поле у каждой колонки для дополнительного сужения (логика AND).
- **Отметки строк (✓)** — первая колонка таблицы: отмечай найденное/обработанное. Отметка
  привязана к **содержимому строки целиком** (устойчива к сортировке и фильтрации) и
  **сохраняется между запусками**.
- **Подсветка совпадений** — жёлтым в ячейках.
- **Клик по ячейке** — значение копируется в буфер обмена и показывается в строке `fx`.
- **Режимы** — один лист или конкатенация всех листов книги.
- **Авто↺** — отслеживает изменение файла и перезагружает.
- **Экспорт CSV** — текущая выборка, UTF-8 с BOM.
- **Ctrl+A/C/V/X** — работают на любой раскладке клавиатуры.

## Стек

Python 3.8+ · tkinter/ttk · [tksheet](https://github.com/ragardner/tksheet) · pandas · openpyxl
(+ pyxlsb для `.xlsb`).

## Установка и запуск

### Готовый exe (Windows, без Python)

Собрать одним файлом со своей иконкой:

```bat
build.bat
```

Результат — `Excel Search.zip` с `Excel Search.exe` (~41 МБ, onefile), запуск двойным кликом,
Python не нужен. Для сборки нужны `pyinstaller` и `pillow`. Exe пакуется в zip, потому что
антивирус на сетевом хранилище удаляет голый PyInstaller-бинарь; `deploy.bat` распаковывает его
в рабочую папку на локальном диске.

### Из исходника

Нужен Python 3.8+ с `pip` (при установке — галочка **Add Python to PATH**).

```bash
python excel_search.py
```

Пакеты `pandas`, `openpyxl`, `tksheet` ставятся автоматически при первом запуске (нужен интернет).
Для чтения `.xlsb` дополнительно: `pip install pyxlsb`.

На Windows можно запускать двойным кликом по `Открыть поиск.bat`.

## Использование

1. **Обзор** → выбрать `.xlsx` / `.xls` / `.xlsb`.
2. Чекбоксами слева выбрать видимые колонки.
3. Вводить запрос в поле **Поиск** — таблица фильтруется на лету.
4. Ставить галочки в колонке **✓** для найденных/обработанных строк — они сохранятся.
5. При необходимости — **Экспорт CSV**.

## Настройки

`excel_search_settings.json` (создаётся рядом со скриптом) хранит: последний файл,
видимость колонок, ширину панели и отметки строк (per-file). В репозиторий не включён.
