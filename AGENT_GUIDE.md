# AGENT_GUIDE — Быстрый поиск в Excel (Excel Search)

Единый источник правды по проекту. Главнее README.txt. При расхождении — верить этому файлу.

Публичный репозиторий: https://github.com/MaxSmych/excel-quick-search (MIT).

## Что это
Standalone desktop-утилита live-поиска по любому Excel-файлу (`.xlsx` / `.xls` / `.xlsb`)
с выбором отображаемых колонок, пофильтрами по колонкам, подсветкой совпадений и экспортом CSV.
Одно окно, один скрипт, без клиент-серверной части. Часть MultiLauncher (модуль SSC UZ).

Стек: **Python 3.8+ / tkinter / ttk (clam) / tksheet / pandas / openpyxl (+ pyxlsb для .xlsb)**.
Тема оформления — Catppuccin Mocha (палитра в словаре `C`).

## Как запускается
- **Собранный:** `deploy.bat` распаковывает `Excel Search.zip` в целевую папку на локальном
  диске → там появляется `Excel Search.exe` (Python не нужен, иконка своя). Запуск двойным кликом.
- **Из исходника:** двойной клик по `Открыть поиск.bat`, либо `python excel_search.py`.
- **Пересборка exe:** `build.bat` (нужны `pyinstaller` + `pillow` в `C:\Python314`). Собирает
  **onedir** в `%TEMP%`, пакует СОДЕРЖИМОЕ папки приложения (exe + `_internal`) в `Excel Search.zip`
  рядом. `deploy.bat` распаковывает его в целевую папку → exe и `_internal` ложатся рядом с
  `excel_search_settings.json` (общий с `.bat`-версией; `APP_DIR` = папка exe, не `_internal`).
  Иконка окна ищется через `_resource("icon.ico")` — работает и из исходника, и из onefile
  (`sys._MEIPASS`); в exe вшивается через `--add-data "icon.ico;."`.
- Зависимости ставятся автоматически при первом запуске функцией `_ensure()`
  (`pip install pandas openpyxl tksheet` — нужен интернет). `pyxlsb` в `_ensure` **не** входит —
  ставится/нужен вручную, если открывают `.xlsb`.
- **Важно:** launcher жёстко прибит к `C:\Python314\pythonw.exe`. На машине с другим путём/версией
  Python launcher не сработает — правится строка в `.bat`.

## Логика (по разделам excel_search.py)
- **Настройки** (`load_settings`/`save_settings`): хранят `last_file`, `recent_files` (список
  последних открытых, до 15), `col_visibility` (видимость каждой колонки), `col_filters`
  (текст пофильтра по колонке, восстанавливается при загрузке — `_on_filter_change`),
  `col_panel_width`, `checked` (отметки строк, см. ниже). Файл `excel_search_settings.json` в
  `APP_DIR`, UTF-8. Сортировка (`_sort_col`) НЕ сохраняется — живёт только в рантайме.
- **Недавние файлы** (`_add_recent`): поле «Файл» — редактируемый Combobox; в выпадающем списке
  последние открытые Excel, выбор (`_on_recent_pick`) сразу загружает файл. Быстрое переключение
  между таблицами в ОДНОМ окне; отметки у каждого файла свои (per-file по пути).
- **Старт** (`App.__init__`): открывает `last_file` из настроек, иначе `DEFAULT_EXCEL` (`维修日报数据.xlsx`
  рядом со скриптом — обычно отсутствует, тогда окно пустое).
- **Режимы чтения** (radiobuttons «Лист» / «Вся книга»): один лист (`xl.parse(sheet)`) или конкатенация
  всех листов с добавленной колонкой `_Лист_` (`mode_var = "all"`).
- **Колонки** (`_rebuild_col_checkboxes`): слева чекбоксы видимости + мини-поле пофильтра на колонку
  (`col_filters`). Кнопки «Все»/«Ноль». Видимость И пофильтры сохраняются в настройки
  (пофильтры — `_on_filter_change`, восстанавливаются при загрузке файла).
- **Сортировка** (`_on_col_header`): клик по заголовку колонки в таблице сортирует по ней,
  повторный клик — реверс (▲/▼ в заголовке). Делается на уровне pandas в `_on_search`
  (`sort_values`, object-колонки — по lower-строке), ЧТОБЫ порядок совпадал с ключами отметок
  и подсветкой. Колонка `✓` не сортируется. Маппинг индекса заголовка → имя через `_display_cols`.
- **Поиск** (`_on_search`): live (trace на `query_var`). Глобальный запрос ищется по ВСЕМ выбранным
  колонкам одновременно (`.contains(..., regex=False)`), плюс AND по индивидуальным пофильтрам колонок.
  Флаг «Регистр» = case-sensitive. Показывается максимум **1000 строк** (`.head(1000)`).
- **Таблица** (`_show_table` / tksheet): подсветка совпадений жёлтым (`_highlight_matches`) —
  только если результат ≤ 300 строк (иначе пропускается для скорости).
- **Отметки строк** (колонка «✓», `checkbox` из tksheet): первая колонка таблицы — чекбокс
  «обработано/найдено». Отметка привязана к строке через СТАБИЛЬНЫЙ ключ = md5-хэш от ВСЕХ
  значений исходной строки (`_compute_row_keys`, служебная колонка `_Лист_` из хэша исключена).
  Поэтому отметка держится за конкретную строку независимо от её содержимого (номера, ФИО и т.п.) и
  не «переезжает» при live-фильтрации, когда состав видимых строк меняется. Идентичные строки-дубли
  получают один ключ и отмечаются вместе (это осознанный компромисс). Хранение — per-file:
  `settings["checked"][<путь файла>] = [хэши…]`. Клик обрабатывает `_on_check(event)`
  (`event.row` → `self._display_keys[row]`, `event.value` → вкл/выкл), сразу пишет в JSON.
- **Клик по ячейке** (`_on_cell_select`): значение попадает в formula bar И копируется в буфер обмена.
  Колонка «✓» (индекс 0) из копирования исключена.
- **Ctrl+A/C/V/X** (`_bind_clipboard_shortcuts`): работают на ЛЮБОЙ раскладке — биндинг по keycode
  (65/67/86/88), не по символу.
- **Авто↺** (`_auto_loop`): поток-демон, каждые 5 сек проверяет `mtime` файла, при изменении —
  перезагружает. Останов через `threading.Event`.
- **Экспорт** (`_export_csv`): текущая выборка (те же колонки/фильтры). По расширению в диалоге:
  `.xlsx` (по умолчанию, `to_excel` через openpyxl) или `.csv` (`utf-8-sig`, BOM). Первым столбцом
  добавляется колонка `✓` (значение `✓` для отмеченных строк, иначе пусто) по текущим отметкам.
  Имя метода историческое (`_export_csv`).

## Константы / ориентиры
- `APP_DIR` — база для постоянных файлов: рядом с **exe** при `sys.frozen`, иначе рядом со
  скриптом. **НЕ** `sys._MEIPASS` (это временная папка распаковки onefile, своя на каждый
  запуск — из-за неё в первой версии exe терял настройки/галочки).
- `SETTINGS_FILE`, `DEFAULT_EXCEL` — в `APP_DIR`. Чтобы exe и `.bat`-версия делили одни
  отметки/настройки, они должны лежать в ОДНОЙ папке (тогда `excel_search_settings.json` общий).
- Иконка окна берётся через `_resource()` = `sys._MEIPASS` (внутри бандла) — это правильно,
  иконка read-only ресурс, а не сохраняемое состояние.
- Лимит отображения: 1000 строк. Лимит подсветки: 300 строк.
- Интервал авто-перезагрузки: 5 сек.
- Палитра — словарь `C` (Catppuccin Mocha).
- Данные заказчика (SSC UZ) — китайские заголовки: `序列号` (серийный), `物料编码` (код материала),
  `品名` (наименование), `库位` (ячейка склада) и т.д. Скрипт полностью Unicode-safe.

## Грабли и правила
- **Не трогать raw-источники**: сами Excel-файлы (`UZ missing.xlsx` и пр.) — источник истины, только чтение.
- **openpyxl read_only + битые dimensions** (глобальная грабля): экспорты FineReport/китайские выгрузки
  в `read_only=True` могут отдавать `max_row=1` (лист «пустой»). Здесь чтение идёт через
  `pd.ExcelFile(...).parse()` (не read_only) — проблема не проявляется. Если появится «исчезновение»
  строк — проверять именно этот момент.
- **Windows cp1251** (глобальная грабля): консоль машины cp1251. Все файловые операции в скрипте уже
  с `encoding="utf-8"` / `utf-8-sig`. Не ломать при правках.
- **Launcher прибит к `C:\Python314`** — см. выше.
- **`.xlsb`**: движок `pyxlsb` не входит в авто-установку `_ensure`. Открытие `.xlsb` без него упадёт.
- **Несколько копий приложения одновременно = риск потери отметок**: все экземпляры пишут в один
  `excel_search_settings.json`, а `save_settings` перезаписывает файл ЦЕЛИКОМ (last-write-wins, без
  merge). Копия, закрывшаяся/сохранившаяся последней, затрёт отметки, сделанные другой копией после
  её старта. Правильный сценарий — ОДНО окно + переключение файлов через список «Недавние»/Обзор
  (отметки per-file). Если понадобится реальный мультизапуск — делать merge-запись (перечитывать
  файл с диска перед сохранением), пока НЕ реализовано.
- **Антивирус на сетевой шаре Z: удаляет PyInstaller-exe**: голый `Excel Search.exe`, скопированный
  в `Z:\Maksim\Перенос\...`, исчезает через секунды — серверный AV на `\\172.16.48.182\share`
  ловит сигнатуру PyInstaller-bootloader. Проверено: удаляется даже при переименовании в `.ex_`
  (AV смотрит содержимое, не расширение). **zip выживает** (внутрь архива AV не лезет). Поэтому
  exe хранится и переносится как `Excel Search.zip`, а `deploy.bat` распаковывает его в целевую
  папку на локальном C: через `tar -x` (bsdtar из `C:\Windows\System32\tar.exe`). На локальном C:
  exe не удаляется. Если боевой Defender всё же съест — добавить папку в исключения.

## Перенос
Проект уже лежит в зеркале `Z:\Maksim\Перенос\Запчасти\MultiLauncher\Быстрый поиск в Excel`.
Любой изменённый файл — сразу копировать в зеркало (см. глобальное правило №10, `update_scripts.bat`).

## Критерии «готово» при правках
1. `python excel_search.py` стартует без ошибок, окно открывается.
2. Загрузка тестового `.xlsx`, live-поиск даёт совпадения, подсветка работает.
3. Настройки видимости колонок сохраняются между запусками (`excel_search_settings.json`).
4. Кириллица/китайские заголовки не бьются.
